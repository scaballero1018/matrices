# PROGRAMA DE OPERACIONES CON MATRICES

Este programa permite realizar diferentes operaciones con matrices ingresadas por el usuario.

## Operaciones disponibles

1. Suma de matrices
2. Multiplicación de matrices
3. Producto de Hadamard
4. Producto de Kronecker
5. Salir del programa

## Archivos del programa

menu.py  
Muestra el menú de opciones al usuario.

entrada.py  
Permite ingresar matrices y mostrarlas en pantalla.

operaciones_matrices.py  
Contiene las funciones que realizan las operaciones con matrices.

main.py  
Es el archivo principal que controla el funcionamiento del programa.

## Cómo funciona el programa

El usuario selecciona una opción del menú.

Luego ingresa las matrices necesarias.

El programa verifica si las matrices cumplen las condiciones necesarias para la operación.

Si las matrices son válidas, se realiza la operación y se muestra el resultado.

Si no cumplen las condiciones, el programa muestra un mensaje explicando el error.

## Cómo ejecutar el programa

En Google Colab ejecutar:

run main.py# matrices
